# SSH Related Topics

This repo contains a set of documents that provide step-by-step instructions for various ssh setup and demos. 

## Documents

Below are the links to the documents available in this repository. Each link provides a detailed guide on the respective topic.

### 1. [SSH Introduction](ssh.md)

This document provides a high-level overview of SSH.

### 2. [Setup SSH Key-Based Authentication](Setup%20SSH%20Key-Based%20Authentication.md)

This guide covers the steps required to set up SSH key-based authentication for secure access to remote servers.

### 3. [GitHub Key-Based SSH Authentication](GitHub%20Key-Based%20SSH%20Authentication.md)
This guide covers the process of creating SSH keys and adding them to your GitHub account to enhance security.

### 4. [Setup SSH Certificate-Based Authentication](Setup%20SSH%20Certificate-Based%20Authentication.md)

This guide covers the steps required to set up SSH Certificate-based authentication for secure access to remote servers.

### 5. [Redundant Hardware-Backed SSH Certificate Authority](YubiKey%20SSH%20CA.md)

This guide provides a step-by-step guide for generating an offline SSH Certificate Authority (CA) private key in an ephemeral RAM disk and importing it into multiple redundant YubiKeys for high availability and disaster recovery.
